# v0.2.0: Tune the game without rebuilding

Gameplay numbers can now be changed in a text file, so playtesting and balancing don't need a programmer. With no tuning file, the game plays the same as v0.1.0.

## New: tuning file
- **Example file:** the game writes `tuning.example.properties` into your config folder at every start. It lists every adjustable value, commented out, with its default and what it does:
  - Linux: `~/.config/simple-astroids`
  - macOS: `~/Library/Application Support/simple-astroids`
  - Windows: `%APPDATA%\simple-astroids`
- **Changing values:** copy it to `tuning.properties` in the same folder, remove the `#` in front of what you want to change, and edit the value, e.g. `ship.maxSpeed = 35` or `enemy.fireInterval = 2.5`.
- **Applying them:** the file is read again for every new game, so there's no need to restart the program.
- **What you can change:**
  - the arena size
  - your ship: thrust, top speed, how fast it coasts to a stop, lives, respawn and shield time
  - your gun: shot speed, range and fire rate
  - the rocks: wave size and growth, speeds, how fast split halves fly apart
  - the enemy ship: health, speed, how long it stays, fire rate, shot speed, aim, how often it comes
  - all scores
- **Mistakes are safe:** a misspelt key, a value that isn't a number, or one out of range keeps its default. The title screen shows what was wrong.
- **Scores:** while anything is changed, the game shows "CUSTOM TUNING" and doesn't record best scores, so tuned games can't beat your real best. Delete the file to play as released.

## Downloads
- **Linux, macOS, Windows:** `SimpleAstroids-0.2.0-<platform>` contains the game with its own Java runtime, so there's nothing to install.
  - Unpack it and start `bin/SimpleAstroids` (Linux), `SimpleAstroids.app` (macOS) or `SimpleAstroids.exe` (Windows).
  - The macOS build isn't signed, so macOS asks the first time: right-click → Open.
- **Any system with Java 25:** `SimpleAstroids-0.2.0-java.zip`. Unpack it and run `java -jar simple-astroids.jar`.

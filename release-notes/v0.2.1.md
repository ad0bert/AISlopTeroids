# v0.2.1: Easier first start on macOS

The game plays the same as v0.2.0. This release only fixes opening the macOS build for the first time.

## Fixed
- **macOS:** clearing the download block with `xattr -cr` stopped with `Permission denied` on every license file of the bundled Java runtime, because those files were read-only. They're writable now, so the command works.
- **Instructions:** "right-click → Open" no longer gets past current macOS versions. The steps below say what works instead.

## Downloads
- **Linux, macOS, Windows:** `SimpleAstroids-0.2.1-<platform>` contains the game with its own Java runtime, so there's nothing to install.
  - Unpack it and start `bin/SimpleAstroids` (Linux), `SimpleAstroids.app` (macOS) or `SimpleAstroids.exe` (Windows).
  - The macOS build isn't signed by Apple, so macOS refuses it the first time ("can't be opened" or "is damaged"). Either go to System Settings → Privacy & Security and click "Open Anyway", or run this once in Terminal (adjust the path if the app isn't in Downloads):
    `xattr -cr ~/Downloads/SimpleAstroids.app`
- **Any system with Java 25:** `SimpleAstroids-0.2.1-java.zip`. Unpack it and run `java -jar simple-astroids.jar`.

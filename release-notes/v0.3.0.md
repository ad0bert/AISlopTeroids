# v0.3.0: Faster, busier, more dangerous

The first playtest made the game a lot harder: more rocks, faster rocks, and an enemy ship that hunts you. This release makes those settings the defaults.

## Changed
- **Rocks:** the first wave has 10 big rocks (was 4), and each wave still adds one, now up to 120. They fly at 13–16 m/s (was 3–6), plus a little more every wave.
- **Enemy ship:**
  - darts around at 20 m/s (was 9)
  - fires twice a second (was every 1.4 seconds)
  - aims within 1.44° (was 3.44°), so its shots are slower than yours but rarely miss: keep moving
- **Shield at start:** the first ship of a game is now shielded for 3 seconds, like every ship after it. With rocks this fast, one could otherwise hit you before you'd had time to look around.

## Fixed
- **Tuning file:** a `tuning.properties` only counts as custom when a value differs from the defaults. A file that lists the default values no longer shows "CUSTOM TUNING" or stops best scores from being recorded.
  - If you tuned v0.2 to exactly these values, your file now matches the defaults and can stay or go.
  - To play as in v0.2, put the old values in `tuning.properties`:

```properties
rocks.firstWave = 4
rocks.max = 12
rocks.minSpeed = 3
rocks.maxSpeed = 6
enemy.speed = 9
enemy.fireInterval = 1.4
enemy.aimErrorDegrees = 3.44
```

## Downloads
- **Linux, macOS, Windows:** `SimpleAstroids-0.3.0-<platform>` contains the game with its own Java runtime, so there's nothing to install.
  - Unpack it and start `bin/SimpleAstroids` (Linux), `SimpleAstroids.app` (macOS) or `SimpleAstroids.exe` (Windows).
  - The macOS build isn't signed by Apple, so macOS refuses it the first time ("can't be opened" or "is damaged"). Either go to System Settings → Privacy & Security and click "Open Anyway", or run this once in Terminal (adjust the path if the app isn't in Downloads):
    `xattr -cr ~/Downloads/SimpleAstroids.app`
- **Any system with Java 25:** `SimpleAstroids-0.3.0-java.zip`. Unpack it and run `java -jar simple-astroids.jar`.

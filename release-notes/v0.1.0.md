# v0.1.0: First release

The classic Asteroids as a 3D first-person game, built on [EngineNamedScratch](https://github.com/ad0bert/EngineNamedScratch) 0.8.1.

## Play
- **The arena:** fly a ship through a cube of space that wraps around on every side. The ship keeps drifting when you let go of thrust.
- **Asteroids:** big ones split into two small ones when shot; small ones shatter. Clear a wave and the next one has one more big rock.
- **Enemy ship:** a red ship shows up every 20–35 seconds. It shoots at you, takes three hits, and leaves after 25 seconds.
- **Lives:** three ships, each shielded for 3 seconds after it appears. The best score is saved.
- **Finding things:** a radar shows everything around you, with a line that tells above from below. The enemy ship and the last three rocks get on-screen markers.
- **Options (`O`):** mouse sensitivity, invert Y, volume, effects volume, fullscreen, vsync, radar. They're saved between runs.
- **Controls:** mouse and keyboard (WASD, Space/Shift, click or Ctrl to fire, P to pause), or a gamepad.

## Downloads
- **Linux, macOS, Windows:** `SimpleAstroids-0.1.0-<platform>` contains the game with its own Java runtime, so there's nothing to install.
  - Unpack it and start `bin/SimpleAstroids` (Linux), `SimpleAstroids.app` (macOS) or `SimpleAstroids.exe` (Windows).
  - The macOS build isn't signed, so macOS asks the first time: right-click → Open.
- **Any system with Java 25:** `SimpleAstroids-0.1.0-java.zip`. Unpack it and run `java -jar simple-astroids.jar`.
